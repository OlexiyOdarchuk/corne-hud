# Прошивка Vial для Corne з екранами corne-hud

Розкладка `vial_tzt` для Corne v3 (`crkbd/rev1`) на платах **RP2040 Pro Micro** (перевірено на TZT HW-467AB,
конвертер `sparkfun_pm2040`). Без неї `corne-hud` не має з ким говорити: саме ця прошивка вміє приймати
кадри, текст і команди по USB.

## Що всередині

- **6 режимів екрана** для кожної половини окремо: статус (шар, WPM, модифікатори), корабель з астероїдами,
  вихованець, еквалайзер, годинник/CPU/RAM/музика, картинка з комп'ютера.
- **Обидва екрани** живуть незалежно: друга половина отримує все від головної через власну транзакцію між половинами.
- **Усі 49 RGB-ефектів** QMK і VialRGB, реакція на натискання, підсвітка поточного шару.
- Vial: mouse keys, комбо, tap dance, Caps Word, 4 шари.

## Клавіші екранів

Шар **Adjust**, правий верхній ряд:

| Клавіша | Дія | Із Shift |
|---|---|---|
| `Y` | наступний режим екрана половини з USB | попередній |
| `U` | наступний режим екрана другої половини | попередній |
| `I` | вимкнути / увімкнути обидва екрани | — |

У Vial ці клавіші є у вкладці **User** (`SCR_MAIN`, `SCR_SIDE`, `SCR_OFF`), їх можна поставити куди завгодно.
Вибір запам'ятовується після вимкнення.

## Прошивка

1. Затиснути **BOOT** і під'єднати половину (або двічі натиснути **RESET**) — з'явиться диск `RPI-RP2`.
2. Скопіювати на нього `.uf2`: `…_left.uf2` на ліву половину, `…_right.uf2` на праву.
   Шити треба **обидві** половини: кожна пам'ятає свою сторону (`EE_HANDS`).

Готові файли — у [релізах](https://github.com/OlexiyOdarchuk/corne-hud/releases).
Помилка копіювання наприкінці — нормально: плата перезавантажується раніше, ніж система закінчує запис.

> [!WARNING]
> Після кожної нової прошивки Vial скидає розкладку і RGB до вбудованих: кожна збірка має новий ідентифікатор.
> Постійні зміни розкладки зручніше вносити в `keymaps/vial_tzt/keymap.c`.

## Збірка

Потрібні `git` і `docker` (або `podman` з аліасом `docker`).

```sh
cd firmware
./build.sh                    # vial_tzt, sparkfun_pm2040 → out/…_left.uf2 і out/…_right.uf2
BOOTMAGIC=no ./build.sh       # без входу в бутлоадер через затиснуту клавішу
```

Перший запуск завантажує `vial-qmk` (зафіксований коміт у `build.sh`) у `firmware/.vial-qmk`.
Розкладку редагувати в `keymaps/`, а не в `.vial-qmk`: перед кожною збіркою вона копіюється туди.

| Файл | Що в ньому |
|---|---|
| `keymaps/vial_tzt/keymap.c` | розкладка, підсвітка шарів |
| `keymaps/vial_tzt/config.h` | піни TZT, сторони, синхронізація половин, RGB-ефекти |
| `keymaps/vial_tzt/screens.c` | режими, клавіші, протокол corne-hud, передача кадрів на другу половину |
| `keymaps/vial_tzt/oled_ui.c` | графіка вбудованих режимів (чистий C, без QMK) |
| `keymaps/vial_tzt/vial.json` | розкладка для Vial і клавіші екранів |

## Перегляд екранів без клавіатури

`oled-sim` збирає `oled_ui.c` на комп'ютері й малює GIF кожного режиму (потрібні `gcc`, Python і Pillow,
а також завантажений `.vial-qmk` — звідти береться шрифт):

```sh
./oled-sim/run.sh /tmp/oled      # → status.gif, ship.gif, pet.gif, eq.gif, pc.gif, sheet.png
```

## Протокол

Опис команд — у [PROTOCOL.md](../PROTOCOL.md). Поточна версія — **2**: тихе перемикання режиму,
завдяки якому corne-hud показує розкладку поверх будь-якого режиму. corne-hud працює і з версією 1,
лише без цього.

## Ліцензія

Код у цій папці базується на QMK і поширюється на умовах **GPL-2.0-or-later**, як і сам QMK.
